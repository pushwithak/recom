# RECOM: Reddit Evaluation for Correspondence of Models

## Overview

**RECOM** (Reddit Evaluation for Correspondence of Models) is an evaluation dataset for assessing how Large Language Models (LLMs) align with community perspectives on open-ended, opinion-driven questions.

This repository accompanies our paper: **"RECOM: Evaluating LLM Alignment with Community Perspectives on Open-Ended Reddit Questions"**

## Dataset Statistics

| Metric | Value |
|--------|-------|
| Total questions collected | 132,728 |
| High-engagement filtered | 25,000 |
| Sampled for evaluation | 15,000 |
| After response filtering | 11,528 |
| Retention rate | 76.9% |
| Source | r/AskReddit (September 1–30, 2025) |
| Reference summarizer | Llama-3.1-8B-Instruct (excluded from evaluation) |
| Models evaluated | Mistral-7B, Qwen2.5-7B, Granite3.1-Dense-8B, Falcon3-10B |

## Dataset Files

### 1. `recom_full.xlsx`
Complete dataset of 15,000 questions with reference summaries and all model responses (8 columns, 15,000 rows).

| Column | Description |
|--------|-------------|
| `id` | Unique identifier |
| `original_post` | Original Reddit question |
| `summary` | Community-derived reference summary (generated by Llama-3.1-8B-Instruct) |
| `generated_answer_falcon3_10b` | Falcon3-10B response |
| `generated_answer_granite3.1-dense_8b` | Granite3.1-Dense-8B response |
| `generated_answer_mistral_7b` | Mistral-7B response |
| `generated_answer_qwen2.5_7b` | Qwen2.5-7B response |

### 2. `recom_filtered.xlsx`
Filtered evaluation dataset after removing refusal responses (8 columns, 11,528 rows). Same schema as above. Questions were removed where *any* model produced a refusal response, ensuring all models are compared on the same set of questions.

**Note:** Llama-3.1-8B-Instruct was used for reference summary generation (`summary` column). Its responses (`generated_answer_llama3.1_8b`) are included in the dataset for transparency but were excluded from all evaluations and comparisons in the paper to avoid self-alignment bias.

### 3. `Human_annotation.xlsx`
Seven annotators evaluated 1,155 question-reference pairs on two binary criteria (3 annotators per group, with annotators assigned to multiple groups): **Relevance** (does the summary address the original question?) and **Coherence** (is the summary clearly written and well-organized?). Annotator names have been anonymized. Columns: `id`, `original_post`, `summary`, followed by paired Relevance/Coherence ratings (Yes/No) for each of the three annotators.

## Filtering Criteria

Responses containing the following patterns were excluded:

| Category | Patterns |
|----------|----------|
| **AI self-references** | "as an AI", "I'm a language model", "as an artificial intelligence" |
| **Capability disclaimers** | "I don't have", "I cannot experience", "I lack emotions" |
| **Role disclaimers** | "I'm not human", "I am not capable of" |

## Key Findings

| Finding | Result |
|---------|--------|
| **BERTScore calibration** | Raw BERTScore F1 of 83.5–84.9% drops to 9.9–17.4% after baseline rescaling, revealing that uncalibrated scores substantially overstate semantic alignment |
| **Length confound** | Response length explains 42–69% of BLEU-1 variance (*r* = 0.65–0.83), with the brevity penalty dominating lexical scores |
| **Consistent model ranking** | Mistral-7B > Granite3.1-Dense-8B > Falcon3-10B > Qwen2.5-7B across all semantic metrics |
| **NLI structural mismatch** | 86–90% neutral classifications, likely reflecting format mismatch rather than meaningful logical relationships |

## Evaluation Metrics

All metrics computed over 11,528 question-response pairs per model:

- **Lexical:** BLEU-1 through BLEU-4, ROUGE-1/2/L F1
- **Semantic:** BERTScore (raw + baseline-rescaled), MoverScore, Cosine Similarity (MPNet, MiniLM)
- **Inference:** NLI (BART-large-MNLI)

## Temporal Contamination Control

The dataset uses questions from September 1–30, 2025, which postdates the training cutoffs of all evaluated models by at least 9 months, ruling out test set contamination:

| Model | Training Cutoff | Verification Source |
|-------|----------------|---------------------|
| Llama-3.1-8B-Instruct (reference) | Dec 2023 | [HuggingFace Model Card](https://huggingface.co/meta-llama/Llama-3.1-8B-Instruct) |
| Mistral-7B-Instruct-v0.3 | ≤ May 2024† | [HuggingFace metadata](https://huggingface.co/mistralai/Mistral-7B-Instruct-v0.3) |
| Qwen2.5-7B-Instruct | ≤ Dec 2023‡ | [Developer disclosure on GitHub](https://github.com/QwenLM/Qwen2.5/issues/525) |
| Granite3.1-Dense-8B-Instruct | Apr 2024† | [Ollama – Model Release Date](https://ollama.com/library/granite3.1-dense:8b) |
| Falcon3-10B-Instruct | ≤ Dec 2024† | [HuggingFace Falcon Blog](https://huggingface.co/blog/falcon3) |

†Cutoff not officially disclosed; model release date used as a conservative upper bound. ‡Stated by the Qwen team on GitHub.
